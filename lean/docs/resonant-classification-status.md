# Resonant classification: kernel-checked completion

## Source-level endpoint

`UploadBroadcast/RegularResonantClassification.lean` closes the positive-excess,
zero-defect classification gap over finite fields. Its hypotheses are an actual
finite-dimensional task of three nested flags, indecomposability, zero defect,
side spanning, and positive side excess. It does **not** assume cross-transversality,
a root-shaped dimension vector, Tits value one, a graph normal form, or a tube
classification theorem.

The compiled endpoints are:

* `dimensions`: the dimension vector is `T₀+nδ` for some natural `n`.
* `tits_and_excess`: Tits value and side excess both equal one.
* `classification`: an actual original-field configuration isomorphism to the
  passive tripod or a canonical resonant Jordan/head model.
* `active_classification`: if some demand properly enlarges its side, the passive
  endpoint is excluded and an actual resonant-model isomorphism is returned.

The passive case is retained deliberately: positive excess does not imply an
active demand. Absolute indecomposability is a separate tensor-extension bridge;
the canonical resonant models already have a proved absolute theorem in
`ResonantBaseChange.lean`. The full-paper base-field-component assembly is tracked
separately and is not claimed by these four classification endpoints.

## Proof chain

1. `RegularHomVanishing.lean` proves positive-defect-to-zero-defect Hom vanishing
   through actual kernel/cokernel reflection equivalences.
2. `RegularSubobjectDefect.lean` derives nonpositive defect for every actual subtask
   of a regular indecomposable, without requiring that the subtask be indecomposable.
3. `SemistableFiltration.lean` constructs a finite actual regular-simple filtration.
   `SemistableMorphisms.lean` proves kernel/image saturation and the zero-or-isomorphism
   statement for maps between regular simples.
4. `RegularTripodPair.lean` constructs the passive tripod T₀ and complementary thin
   task δ−T₀. Both are proved regular-simple. Four explicit Hom/kernel/annihilator
   equivalences give four directed Hom–Euler identities using rank-nullity.
   Every other regular simple has zero Hom and zero Euler pairing with this pair
   in both directions. Positive side excess implies `Hom(T₀,T)` has positive rank.
5. `QuiverExtensions.lean` proves that Hom rank equal to Euler implies surjectivity
   of the concrete vertex-to-arrow coboundary map. Block-triangular shears then split
   every corresponding actual extension. `RegularExtensionGeneration.lean` transports
   the actual regular filtration into `ExtensionGenerated` certificates.
6. `ExtensionBlockSeparation.lean` separates extension-generated orthogonal classes
   using actual block maps. The nonzero map from T₀ detects which class contains an
   indecomposable. `RegularPositiveCross.lean` concludes that a positive-excess regular
   indecomposable is generated by T₀ and δ−T₀. `CrossIntersectionClosure.lean` proves
   cross-path injectivity is extension- and isomorphism-closed. Thus
   `RegularPositiveCross.cross_disjoint` proves **all six** distinct `Uᵢ∩Aⱼ=0`,
   over arbitrary fields, without a dimension-family hypothesis.
7. `GeneralTransverseClassification.lean` constructs diagonal graph coordinates from
   these actual flags, allowing arbitrary private and tripod dimensions initially.
   `MarkedSubspace.lean` forces the marked kernel to be one-dimensional and the
   nilpotent operator to be a single chain. This derives the dimensions rather than
   assuming them. `ResonantFlagNormalization.lean` and `ResonantClassification.lean`
   construct the final configuration isomorphism.

## Explicit graph classification

`ResonantClassification.lean` proves the graph converse directly. Actual flag
idempotents correspond to operators commuting with `N(x,t)=(Jx,hx)` and preserving
its marked scalar line. A stable nonunit endomorphism forces `J` nilpotent over a
finite field. `MarkedNilpotent.lean` implies `ker N` is exactly the marked line,
so `h` detects `ker J`. The observability map `x ↦ (h(J^i x))ᵢ` is an actual linear
equivalence conjugating `J` to the Jordan shift and `h` to the head functional.
This does not invoke Kac uniqueness or disguise a classification premise.

## Additional verified reductions

The following independent reductions remain useful, although the final proof
uses regular-simple extension separation instead of a full singular-pencil analysis:

* `TripodSubobjectExclusion.lean`: actual enlarged-tripod Hom obstruction, pairwise
  side disjointness, and `Uᵢ∩P=Aᵢ∩P` for the intrinsic tripod subspace.
* `TripodQuotient.lean`: actual quotient task, independent quotient private sides,
  and preservation of demand increments.
* `ResonantRelationReduction.lean`: arbitrary paired remote coefficient maps;
  failure of a boundary/coupling obstruction constructs a stable tripod projector.
* `ResonantKernelSupport.lean`: a detected boundary mode has nonzero support on
  every private side, using an explicit sparse subtask and its defect.
* `ResonantSeedEmbedding.lean`: an actual injective first-resonant-block map, rather
  than only an abstract numerical root.
